# Model Card — 계층 분류기 (Stage 1 Red 이진 + Stage 2 Yellow 하위형)

> **45만 명을 실제로 스코어링하는 모델의 카드다.** 종전에는 위험을 구동하지 않는
> 보조 모델(`sparse_linear`)만 모델카드·교차검토 승인·모니터링·승인 경로를 갖추고,
> 실제 배포 모델은 카드 없이 운영되고 있었다(기술검토 P1-6 — 거버넌스 대상 전도).
>
> **상태: 식별부 전사 완료 (2026-09-07).** 값의 출처는 **배포 보관본**이며 운영 PC
> 에서 실제로 로드돼 있는 번들과 같은지는 **확인하지 않았다**(A0 ② 는 API 미기동으로
> 미확인). 그 경계를 §식별에 적어 둔다.

## 식별

| 항목 | 값 |
|---|---|
| 아키텍처 | 2단 계층. **Stage 1** = Red 이진(XGBoost) · **Stage 2** = Yellow 하위형 다중분류(XGBoost) |
| Stage 2 라벨 공간 | 7-class — Y_TRIPLE / Y_DOUBLE / Y_DDI_MAJOR / Y_DDI_MOD / Y_DUP / Y_FRAG / No_Alert |
| 입력 피처 | 22종 (약물 수·7일 약물 수·기관 수·DDI 중증도별 4종·Triple Whammy·QT 위험 수·중복 **5종**·고위험/신/간 위험약 3종·CYP 3종·연령·성별) |

| 시간 성격 | **same-window** 위험 분류기(현재 피처 → 현재 위험). future-onset 홀드아웃 트랙이 아니므로 freeze-safe |

| Stage 1 축약 조건 | Red 표본이 임계 미만이면 **상수 비-Red 더미**로 대체되고 Stage 2 만 학습된다. 그 사실은 번들 메타의 `stage1_trained` 로 기록된다 |

## 의도된 용도와 운영 역할

> 이 절의 제목은 "승인 범위" 가 아니다. **승인자·승인일·승인 상태가 없다.** 보조
> 모델 카드에는 교차검토 승인 기록이 있으나 이 모델에는 없다 — 그것이 P1-6 이
> 지적한 전도의 실체다.

**이 모델은 단독 결정 함수가 아니다.** 최종 등급은 규칙층·모델·백스톱의 **단조 상향
결합**이다. 그러나 **이 모델이 최종 등급을 올리지 않는다는 뜻은 아니다.**

| 산출 | 쓰임 |
|---|---|
| Stage 1 Red 확률이 상위 임계 이상 | **Red 확정 · 즉각 개입.** Stage 2 를 건너뛰고 **최종 등급을 올린다** |
| Stage 1 확률이 두 임계 사이 | Stage 2 하위형 + `red_suspect` — 검수 큐 분기 |
| Stage 2 Yellow 하위형 | 개입 유형 배정 |

**금기 백스톱은 무조건 보장이 아니다.** 모델과 무관하게 동작하지만 **금기 탐지에
성공했을 때 강제 승격**하는 것이며, 그 계산이 예외를 내면 예외를 잡고 **진행한다.**
백스톱이 도입된 경위 자체가 "Stage 1 임계가 퇴화해 일부가 누락된다" 는 관측이었다.

**탐지 전용 플래그는 이 모델을 억제하지 않는다.** 그 플래그가 끊는 것은 규칙층의
등급 승격이며, 결정적 백스톱·하위형 하한·ML 등급은 그대로 둔다.

**탐지 전용 플래그는 이 모델을 억제하지 않는다.** 그 플래그가 끊는 것은 규칙층의
등급 승격이며, 결정적 백스톱·하위형 하한·ML 등급은 그대로 둔다.

**승인되지 않은 것** — 이 모델의 출력을 **임상 성능**으로 인용하는 것. 아래 §미검증
항목 첫 줄이 그 이유다.

## 미검증 항목 — 이 카드의 본체

**P1-6 이 요구한 것은 파일의 존재가 아니라 이 표다.**

| 항목 | 상태 | 닫는 작업 |
|---|---|---|
| 규칙-독립 정답 대비 **임상 성능** | **없음** — 골든셋 0건 | E1·E1a, 게이트 G-D |
| 계층 CV 지표의 의미 | 높은 값은 **규칙 재현 충실도**다. 라벨이 규칙 파생이므로 성능이 아니다 | 용어 규율(S1.11) |
| 확률 **캘리브레이션** | **없음** | E3 (E1 의 독립 정답이 선행) |
| **서브그룹 공정성** 감사 | **없음** | E4 |
| **시간분할** 검증 | **없음** — 무작위 분할 | M10a·M10 |
| 기준서 조건과의 정합 | **1:1 아님.** 라벨 경로는 기준서 Red 7조건 중 일부를 강등·치환·누락했다 | M-3 측정 → D2 결정 |
| QT 피처 | **학습에서 상수 0** — ETL 집계가 대입하지 않으므로 이 모델은 QT 를 학습하지 못했다. **서빙 요청 경로는 ATC 기반으로 값을 계산하므로 0 이 아닐 수 있다** — 학습 분포와 서빙 입력이 어긋난다 | 차단 요인 B-3, M-4 |
| 라벨 의미 가드 | 번들에 기준서 버전이 실리지만 **로더가 읽지 않는다** | D3 |
| 학습 코호트 **재현** | **불가** — 번들에 입력 파일 목록·기간이 없다 | B-1 → M-1 (이후 번들은 M-2 스탬프) |

## 한계

- **라벨이 규칙 파생이다.** 이 모델이 잘 맞춘다는 것은 규칙을 잘 흉내 낸다는 뜻이며,
  규칙이 틀린 자리에서는 함께 틀린다. 규칙과 독립인 정답으로 재본 적이 없다.
- **검수 큐가 비어 있다 — 실측으로 확인됐다.** `tau_red − tau_review` 간격이
  **1.0e-06** 이다. 두 임계 사이에 들어오는 확률 구간이 사실상 없으므로 `red_suspect`
  가 붙는 경계 사례가 거의 발생하지 않는다. **경계 검토 경로가 작동하지 않는다.**
- **Stage 1 은 학습됐다** (`stage1_trained=True`, Red 1,660건). 다만 Red 비율이
  1,660/453,677 = 0.37% 로 낮고 τ 가 0.99997 에 붙어 있다 — 그 조합이 위의 밴드
  붕괴를 만든다.
- **QT 는 학습에서 상수였다.** 학습 피처가 0 으로 고정돼 있었으므로 이 모델은 QT 를
  학습하지 못했다. 반면 서빙 요청 경로는 ATC 기반으로 값을 채울 수 있어, **학습
  분포와 서빙 입력이 어긋난다.**
- **계층 번들 로드가 실패하면 단일 모델 경로로 내려간다.** 그 경우 하위형 배정과
  검수 큐 분기가 사라지며, 응답만 보고는 어느 경로가 돌았는지 구분하기 어렵다.
- **백스톱 계산이 예외를 내면 잡고 진행한다.** 금기 승격이 조용히 빠질 수 있다.
- **탐지 전용 배포에서도 이 모델이 단독으로 Red 를 낼 수 있다.** 그 플래그는 규칙층의
  등급 승격만 끊고 ML 등급은 결합에 그대로 들어간다. 그때 나온 Red 는 규칙 사유가
  붙지 않을 수 있으며, **A5 의 "사유 없는 Red" 판정이 보는 경로가 이것이다.**
- **학습 코호트를 재현할 수 없다.** 배포 번들에 입력 목록·기간·코드 참조가 없다.

## 운영 모니터링

| 신호 | 의미 |
|---|---|
| `stage1_trained=false` | Stage 1 미학습 번들 — Red 미탐지 한계. **배포 전 검토 신호** |
| `tau_red − tau_review` 간격 | 붕괴 시 검수 큐가 비어 경계 검토가 작동하지 않는다 |
| 피처 PSI | 학습 시점 분포와의 이탈. **현재 실효 커버리지는 좁다**(M7 잔여) |
| 규칙-ML 등급 불일치 | 결합의 어느 항이 등급을 올렸는지의 단서 |
| 번들 SHA 대조 | 메타 기록값과 실제 파일의 일치 (A0 ③) |
| 계층 로드 실패 | 단일 모델 경로로 전환 — 하위형·검수 큐가 사라진다 |
| 백스톱 예외 | 금기 승격이 조용히 빠진다 |

**이 표는 무엇을 볼지만 적는다.** 각 신호의 **구현 여부·임계·담당자·초과 시 조치**는
아직 정해지지 않았다. 신호 목록이 곧 모니터링 체계는 아니다.

## 학습 ↔ 서빙 일관성 (검증 포인트)

| 가드 | 동작 |
|---|---|
| 번들 SHA-256 | 모델 파일 무결성 검증 — 불일치 시 로드 거부 |
| Stage 2 라벨 공간 | 현행과 다른 구 번들은 로드 거부 |
| 빈 `feature_cols` | 명시적 로드 거부 |
| DDI 의미 버전 | 누락·불일치 시 거부 |
| 피처 스키마 | 검증 후 거부 (완화 탈출구는 이미 만료) |
| 직렬화 인코더 정합 | 검증 대상 |
| 일반 피처 의미 버전 | **일괄 거부가 아니다** — 불일치 시 일부 규칙 파생 피처의 계산을 게이팅한다 |
| **기준서 버전** | **검사하지 않는다** — 번들에 실리지만 로더가 읽지 않는다. D3 가 만든다 |
