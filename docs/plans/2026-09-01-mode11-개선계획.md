## S1. 범위 · 전제 · 성공 기준

### S1.1 이 계획이 푸는 문제

기술검토가 확인한 29건을 **실행 가능한 작업 단위로 전환**하고, 그 순서를 임상·규제 영향에 따라 고정한다. 검토서가 "무엇이 잘못됐는가"라면 이 계획은 "누가 무엇을 언제 하는가"다.

1. 지금 운영 중인 시스템에서 **꺼져 있는 안전장치**를 언제, 어떤 용량 결정과 함께 켜는가
2. 45만 명 라벨 체계가 **미승인 임상 기준** 위에 서 있는 상태를 어떻게 해소하는가
3. "이 시스템의 위험등급 예측 정확도"에 **언제 답할 수 있게 되는가**

### S1.3 기준선 고정 — 검증된 사실

착수 전 확정 사항. **1회차 리뷰에서 초안의 사실 오류 4건이 정정되었다.**

| 항목 | 확인된 사실 | 근거 |
|---|---|---|
| 실적 확정 커밋 | `main` = `origin/main` = `8a1157c` (2026-07-15) | git |
| 안전망 수정 병합 상태 | `a98a0a4`는 **main 미포함**, 그러나 **현재 작업 브랜치는 이미 포함** | `git merge-base --is-ancestor` |
| Step 0 코드 | `predict` 안에 **존재**하며 SafetyNet보다 먼저 호출된다 | 서빙 예측 모듈 |
| Step 0 활성 여부 | **기본 비활성.** 환경변수 `서빙 환경 플래그(이름 해소)`가 참일 때만 실행 | 서빙 예측 모듈 |
| 활성화의 운영 영향 | 코드 주석이 명시 — **켜면 적격군 기준 즉각 개입 대상이 28배** | 서빙 예측 모듈 |
| 배포본 식별자 | 번들 메타에 **커밋 해시 없음.** 모델 파일 SHA-256 2개만 존재 | 실측 |

**초안이 틀렸던 것** — "워킹트리에 미병합 수정이 반영된 것으로 보임"은 오진이었다. `git status`는 clean이며, Step 0 코드가 보이는 이유는 현재 브랜치가 `a98a0a4`를 조상으로 포함하기 때문이다.

**따라서 P0-1의 성격이 바뀐다.** 남은 일은 "코드를 옮기는 것"도 "병합하는 것"도 아니다 — **main 병합 + 운영 용량 결정 후 플래그 활성화**다. 28배라는 숫자가 이 결정의 무게다.

#### S1.3.1 기준선 확인의 분기

번들 메타에 커밋 해시가 없으므로 커밋 단위 3자 diff는 **완결 불가**다. 대신 다음으로 대체한다.

| 확인 | 방법 | 결과에 따른 P0-1 정의 |
|---|---|---|
| 운영 PC 소스 스냅샷 | 파일 해시 대조 | `8a1157c` 상태 → 병합 + 플래그 결정 |
| | | `a98a0a4` 포함 → 플래그 결정만 |
| 운영 PC 플래그 값 | `/health`의 `serving_flag_state` | 켜져 있으면 P0-1은 이미 해소, **28배 부하가 이미 발생 중**이므로 즉시 확인 필요 |
| 배포 번들 동일성 | `stage1_sha256`/`stage2_sha256` 대조 | 불일치 시 배포본 재식별 |

**A0의 첫 산출물은 "3자 diff"가 아니라 "운영 PC의 소스 해시 + 플래그 값 + 번들 SHA"다.**

### S1.5 범위

**포함** — P0 3건 전량, P1 14건 전량, 그리고 이들이 요구하는 측정·문서·승인 절차. P2 12건은 보고서 개정으로 처리 완료(방식이지 별도 작업 아님).

**제외**

| 제외 | 사유 | 재개 조건 |
|---|---|---|
| 신규 모델 아키텍처 | 라벨이 규칙 파생인 한 ML 부가가치 없음 | 완전 성공의 독립 골든셋이 **규칙층 자체를 임상적으로 기각**하면 즉시 재논의 |
| 전국 확대 **인프라 구축** | PoC 범위 밖 | 4단계 이후 |
| future-onset **연구트랙 재개** | 해제 트리거 없음(Gate 5A·5B 공식 취소) | 없음 — 무기한 |
| DDI_MODEL_04 **엔지니어링** | 별도 트랙·별도 DoD | 해당 없음 |

**제외 경계 — 리뷰에서 정정된 3건**

1. **PIA·목적 외 이용 법적 근거는 포함이다.** "확대 인프라 제외"가 "확대에 필요한 법적 전제까지 제외"로 미끄러지면 P1-11을 사실상 제외한 것이 된다. 인프라 구축은 제외, **45만 표본의 법적 근거·PIA 항목 신설은 포함**.
2. **freeze-safe 시간 평가는 포함이다.** 초안은 "신규 홀드아웃 확보가 선결"이라 썼으나 정책 원문에 그런 해제 경로는 없다(Gate 5A·5B 폐기). 제외되는 것은 홀드아웃 튜닝이며, **Jul~Nov 내부 시간분할**은 freeze-safe이므로 P1-1의 설계 공간으로 열려 있다. 이것이 없으면 P1-1은 "시간분할 없음"이라 한 줄 쓰는 일로 축소된다.
3. **DDI_MODEL_04 제외는 엔지니어링 한정이다.** P2-4·P2-10·P2-11이 그 장에 걸쳐 있으므로 **보고서 정정 책임은 본 계획에 남는다**. 아니면 A-17 "달성 100%"가 지적된 채로 남는다.

**침묵하지 않을 것** — 보조 DL `sparse_linear`는 DDI_MODEL_04가 아니라 MODE_11 트랙이며 P1-1의 핵심 오염원이다. 포함이다.

### S1.6 성공 기준

초안의 "검토서 우선순위와 1:1 대응한다"는 **거짓이었으므로 철회한다**(기본 성공이 P1 14건 중 9건만 담았다). 아래는 우선순위 기반의 3단계이며 1:1이 아니다.

| 수준 | 조건 |
|---|---|
| **최소** | P0 3건의 **운영 종결** — ① main 병합 + 합성 케이스 10건으로 Top-10 발화 실증 + 플래그 활성 범위 결정 ② M1 FN 실측을 첨부한 기준서 **서명 완료** ③ 규제 **회신 수령** 및 사용 목적·자동 통보 범위 재정의 반영 |
| **기본** | 최소 + P1-2(골든셋 프로토콜) · P1-1 · P1-3~7 · P1-10 · P1-12~14 |
| **측정 가능 (골든셋 v1)** | 기본 + 골든셋 1,500건(규칙-독립 정답, κ 하한 충족) + **규칙-독립 등급 대비 Recall(층화)·Precision(가중)** 최초 산출 |

**변경 사유 3건**

- **"배포 완료" → "발화 실증 + 활성 범위 결정".** 증거 없는 병합은 해소가 아니다. 게다가 병합만으로는 플래그가 켜지지 않는다.
- **"기준서 승인" → "FN 실측 첨부한 서명".** 실측 없는 서명은 미서명 초안을 서명된 초안으로 바꾸는 것이다.
- **"재분류 대응 착수" 삭제.** 착수는 법무 티켓만 열고 아무것도 바꾸지 않아 최소 성공이 항상 달성 가능해진다. **회신 수령**으로 바꾼다.
- **"완전 성공" → "측정 가능(골든셋 v1)".** 사용 목적이 ADR 차단 CDSS인데 "완전"이라 부르면 목적 대비 완전으로 오독된다. 이 계획은 임상 효과를 증명하지 않는다.

**기본 성공에 P1-2를 넣은 이유** — 프로토콜(규칙서 블라인드 + Precision 분리)을 고치지 않고 골든셋을 쌓으면 나중에 1,500건을 버려야 한다. 지금이 가장 값싼 시점이다.

**P1-5·P1-7이 최소가 아닌 이유** — 검토서 등급 규약(`[치명]`=P0)을 존중한다. 다만 둘 다 기본 성공의 앞자리에 두고, P1-7(사유 소실)은 재학습이 불필요하므로 0-A에서 함께 처리한다.

### S1.7 선행 순서 (불변식)

성공 수준은 포함 관계지만 작업에는 방향이 있다. 아래를 어기면 계획이 S1.11을 스스로 위반한다.

```
A0 운영 상태 확인 ──▶ P0-1 작업 정의
M1 FN 실측 ──▶ 기준서 서명(D1)
P1-2 프로토콜 확정 ──▶ 골든셋 적재(E1)
규제 회신 ──▶ 비SaMD 주장 확정(D4)
기준서 서명(D1) ──▶ 재학습(E2)
```

### S1.8 용어의 조작적 정의

| 용어 | 판정 가능한 정의 |
|---|---|
| 안전망 정상화 | **운영 트래픽에서** Top-10 발화가 관측됨(A5). 합성 케이스 통과와 범위 문서화는 선행 조건이지 정상화가 아니다 |
| 기준서 승인 | `CLINICAL_STANDARDS` 승인란 4칸 서명 + 문서 상태 "초안" → "확정" + M1 결과 첨부 |
| 지위 확정 | 규제 회신 문서 수령 + §6.1 사용 목적·자동 통보 범위가 회신에 맞게 개정됨 |
| 위험등급 예측 정확도 | **규칙서를 블라인드한** 임상 정답 대비 층화 Recall·가중 Precision. 규칙 재현 지표(계층 CV·M10)는 이 용어를 쓰지 않는다 |

### S1.11 이 계획이 명시적으로 거부하는 것

- **달성률 집계로 성과를 보고하지 않는다.** 진척은 P0/P1 항목의 개별 상태로만 보고한다.
- **골든셋 없이 성능을 주장하지 않는다.** 규칙 재현 충실도를 성능으로 인용하지 않는다.
- **미측정 상태에서 임상 결정을 내리지 않는다.** Red 조건 강등·위험약물 목록 확장 보류가 이 패턴으로 발생했다. A8이 이 거부의 계획 내 강제 장치다.

## S2. 0단계 — 즉시 조치 (D+0 ~ D+14)

### S2.2 A4 — 활성 방식 (선택지 6개)

**M0 게이팅은 방식별로 다르다.** 탐지 전용·섀도는 개입 라우팅을 바꾸지 않으므로 **M0를 기다리지 않는다**. 전면·샘플링만 배포 코호트(453,677) 기준 재측정(M0)을 선행 조건으로 한다. M0를 A4 전체의 선행으로 두면 탐지 전용 권고와 모순되고 P0-1이 14일보다 길게 열린다.

| 방식 | 내용 | D+14에 선택 가능? |
|---|---|---|
| **탐지 전용** | 플래그 ON으로 Top-10을 `risk_reasons`·로그·CE 후보에만 남기고 ACTION·문자·즉각개입 라우팅은 현행 유지 | A1a가 가능 판정이면 **가능** |
| 섀도/로그 전용 | 운영 개입 없이 발화율만 관측 | 가능 |
| 무작위 샘플링 | 무작위 1~5% EDI-only 요청에만 활성 | **가능** — 임상 등급으로 자르지 않으므로 D1 불요 |
| 전면 활성 | 플래그 ON, 전 경로 | 재측정 결과가 용량 내일 때만 |
| 단계적 활성 | 고위험 부분모집단부터 | **불가** — 대상 정의가 임상 판단이라 D1(2단계) 필요. D+14에 고르면 A8·S1.11 위반 |
| 활성 보류 | 병합만, OFF 유지 | 가능하나 **종결 아님**(아래) |

**탐지 전용이 기본 권고다.** 검토서 P0-1이 닫으라 한 것은 **무발화**이고, 28배는 **개입 인력 한도**다. 둘을 한 플래그에 묶으면 용량 부족이 탐지 미가동의 사유가 된다. 탐지만 켜면 P1-5(위해 탐지 수단 부재)도 부분 해소된다.

### S2.3 활성 보류의 지위 — 종결이 아니다

> **활성 보류는 0-A의 일시 정지이지 최소 성공 ①의 종결이 아니다. 최소 성공 상한 D+120 안에 탐지 전용·섀도·샘플링·전면 중 어느 하나로 운영 발화가 관측되지 않으면 P0-1은 미달이다.**

보류를 고르면 S1.9에 따라 운영 제한 범위를 문서 통보하되, **0-A는 열린 상태로 유지**하고 게이트 G-A는 통과하지 않는다. 초안은 보류 시 A5를 제한 통보로 대체하고 0단계를 종료했는데, 그러면 D+14에 병합하고 플래그를 끄고 "Top-10 미발화 상태로 운영 중"이라 통보하는 것으로 최소 성공 ①이 닫힌다. S1이 지운 "착수 = 성공"과 동형이다.

**단계적 활성을 고른 경우도 0단계 안에 닫히지 않는다** — D1 이후로 A5가 밀리므로 동일하게 0-A를 열어 둔다.

### S2.5 B2 의뢰 문서 — 균형 요건

질문이 답을 결정한다. 가중 사실만 넣으면 과잉 규제, 완화 사실만 넣으면 과소 규제다. **양쪽을 함께** 기재한다.

**가중 사실**

- 사용 목적 선언이 "예방 가능한 ADR을 사전 차단하는 임상 의사결정 지원 체계"임
- 출력이 위험등급 + 수행 가능한 개입 행위임
- 자동 문자 안내가 약사 사전 검토 없이 21만 명(46.29%)에게 나가는 **설계**임 — A0에서 실제 발송 경로가 확인되면 시제를 사실로, 미구현이면 "설계 단계"로 정확히 표기
- HITL이 지키는 구간은 즉각+전화 **17.1%뿐**이며 전체 알림 발생률은 99.96%임
- 임상 기준서가 **미서명 초안**이고 Red 7조건 중 6개가 전문가 서명 없이 강등된 채 45만 명을 스코어링 중임
- 독립 임상 성능이 **없음**(골든셋 0건). 계층 CV PR-AUC 1.0은 규칙 재현 충실도임
- 시판 후 감시 부재 — 감사로그 0, 대시보드 가동 0, CE 탐지 불가, 비상 절차 발화 불가
- 이미 453,677명 대상 배포본이 **현재 가동 중**임

**완화 사실 (반드시 함께)**

- 실질 결정 함수는 임상 규칙 모듈이며 ML은 그 위의 **단조 상향 결합**임. 금기는 모델 독립 백스톱이 강제하고 `rule_floor`가 단방향 하한을 검
- 안전망 일부가 플래그로 비활성이며, 활성 시 개입 대상 증가는 **150명 하루치 표본 기준 28배(점추정, 신뢰구간 없음)** — 배포 코호트 재측정 예정
- 플래그 활성이 안전망을 **전 복구하지 않음** — ATC 기반 QT 계수 등 #14 잔여는 별도 경로가 필요

**선행 자기분류 고지** — 보고서와 DoD-18이 이미 비SaMD 유지를 전제했음을 밝힌다. 사후 유권해석임을 숨기면 해석이 "신규 계획"으로 간다.

**금지** — "ML은 정보 필드일 뿐"이라는 기존 논거를 그대로 제출하지 않는다. 보조 DL 트랙에만 참이다.

| **M-3** | **기준서 6조건의 측정용 구현** — 현 코드에 없는 `Major≥3`·`10종+Major`·`고위험약+Major`를 **측정 전용 모듈**로 구현. 서빙·라벨 경로는 건드리지 않는다 | B-2 |

**M-3을 서빙에 넣지 않는 이유** — 기준서 조건을 서빙에 되살리는 것은 D2(위계 재확정)의 결정 사항이다. 1단계는 "되돌리면 얼마가 되는가"를 재는 것이지 되돌리는 것이 아니다.

**QT(조건 7)는 측정 불가로 확정한다.** 피처가 없으므로 M1f의 판정은 "불가"이며, 승인 패킷에 **"이 칸은 공란 — 측정 수단 부재"** 로 명시한다. 이것이 측정 결과다.

### S3.5 측정 설계 원칙

- **재현 가능해야 한다.** 시드 고정, 입력 SHA-256 기록, 산출 스크립트 커밋. 커밋 메시지에만 수치를 남기지 않는다(28배가 그렇게 남아 있었다).
- **분모를 명시한다.** 모든 수치에 코호트·기간·표본 크기를 병기하고, **M-1 코호트가 배포 번들과 다르다는 사실을 함께 적는다.**
- **완료 판정은 산출물 존재이며 결과의 좋고 나쁨이 아니다.**
- **측정이 결정을 대신하지 않는다.**

### S3.6 1단계 종료 조건과 정직한 범위

- M-1~M-3 선행 구현 완료
- M0(0단계 중) · M1·M1b~M1f · M2~M5 산출
- M10a·M10·M11 완료
- M6~M9 완료

**닫히는 P1은 P1-6(카드가 충실할 때)과 P1-1의 KPI 분리(M11)뿐이다.** P1-3·4는 입력을 만들고, P1-5·12·13은 조각만 닫으며, P1-7은 0단계, P1-2·10·14는 뒤 단계다. 종료 보고에 이를 그대로 적는다.

**일정** — 1단계는 **D+21~90**이다. 산정 근거와 임계경로는 §S6.

## S4. 2단계 — 임상 결정 · 거버넌스

> **리뷰 2회차 반영.** 검증에서 드러난 것 — ① 승인란은 "4칸 전부 공란"이 아니라 **승인 상태 "승인 대기", 약물전문가 행에 `-`와 일자만, 나머지 3행 공란**이다. ② `clinical_standards_version`은 번들에 **들어가지만 로더가 읽지 않는다** — D3는 신규 구현이다. ③ 추인 위험이 거부 위험보다 크다.

### S4.1 작업

| WBS | 작업 | 선행 | 완료 판정 |
|---|---|---|---|
| **D1** | 기준서 개정·승인 | **M1 계열** · B1 | 승인 4인 서명 + 상태 "초안"→"확정" + **각 서명자가 판단 근거를 1문단씩 기재** |
| **D2** | 개입 위계 재확정 (`SUB_RANK`, Red 조건 범위, 알림량 정책) | M1~M5, **D1과 동시** | 변경분이 기준서 본문에 반영되고 **같은 서명에 포함**. D1만 찍고 D2를 미루는 것을 금지 |
| D3 | 라벨 의미 가드 **구현** — 로더가 `clinical_standards_version` 불일치를 로드 거부 | D1 | 구 버전 번들 load=False 실증 |
| D4 | 비SaMD 논거 재작성 | **B2 회신** | 규제 의견서 + §6.1 개정 |
| D5 | 골든셋 프로토콜 확정 | D1 | 규칙서 블라인드 조항 + Precision 보정 방식 |

### S4.2 D1 — 추인을 막는 장치

승인 요청 패킷(M1 계열 전량 · 변경 이력 · P1-7 영향 · 규칙층 미검증 M2·M3·M5 · 등급 출처 M4 · M0와 A4 결정 · 외부 대조/독립 성능 부재 고지)은 **요청 성립 조건**일 뿐 추인을 막지 못한다. 아래를 강제한다.

1. **서명자별 판단 근거 1문단.** 각 4인이 "무엇을 보고 무엇을 승인했는지"를 적는다. 빈 서명은 무효.
2. **조건별 명시적 결정.** 강등 5조건 각각에 대해 **유지 / Red 복원 / 조건 변경** 중 하나를 고르고 M1b(반사실 Red 규모)를 근거로 인용한다. 일괄 승인 금지.
3. **QT 공란의 명시적 수용.** 측정 불가임을 인지했다는 서명 항목을 따로 둔다.
4. **재검토 기한.** 승인은 무기한이 아니라 골든셋 산출(3단계) 후 재확인 대상임을 문서에 박는다.

**D1이 막히는 경우(R-P8)** — 강등 유지 거부 시 라벨 롤백·위계 재설계가 범위에 편입되고 3단계 일정이 전면 재산정된다. **거부는 실패가 아니라 정상 결과다.** 계획은 거부 쪽이 더 비싸지지 않도록 이 분기를 게이트 심사 자료에 미리 적어 둔다.

### S4.3 D4 — 회신이 없을 때

S1.7 불변식은 "회신 → 비SaMD 확정"이다. 회신 지연 시 조건부 통과를 허용하되, **G-C는 회신 또는 잠정 조치를 요구한다**(S5.4). 잠정 조치란 회신 전까지 자동 문자 안내를 제한하거나, 제한하지 않는 결정을 사업 총괄 명의로 문서화하는 것이다. "의뢰했음"만으로 3단계에 들어가지 않는다.

### S4.4 2단계 종료 조건

- **D1 + D2 서명 완료** (분리 불가)
- D3·D5·D7 완료
- D4는 회신 수령 또는 잠정 조치 문서화
- D6 — 0-A가 열려 있었다면 여기서 닫는다

## S5. 3~4단계 · 자원 · 게이트

> **리뷰 2회차 반영.** 검증에서 드러난 것 — ① **EDI→ATC5 권위 크로스워크가 저장소에 없다**(외부 조달 필요). ② CYP "25피처"는 부정확한 수치다(코드 30열, 환자 추출 18, 소비 3). ③ **골든셋 파이프라인이 `expert_label`을 `rule_label`로 복사**하고 있어 독립 정답 워크플로가 미구현이다. ④ **금기=0 부분모집단은 Stage 1 정답이 전부 0이라 보정기를 학습할 수 없다.** ⑤ Stage 1은 단순 제거 불가.

### S6.3 외부 리드타임 — 통제 불가

### S6.4 임계경로

최소 성공 3건이 각각 언제 닫히는가.

| 최소 성공 | 경로 | 예상 |
|---|---|---|
| ① 운영 발화 | A2→A0→A1a→A3→A1→A4→A5 | **D+21** (탐지 전용) / M0 대기 시 D+45 |
| ② 기준서 서명 | M-1·M-3 → M1 계열 → D1 | **D+118~146** |
| ③ 규제 회신 | B2 의뢰 → 회신 | **D+63~175** |

**임계경로는 ③(규제)이며, 분산이 가장 크다.** ②가 그 다음이고, ①은 탐지 전용을 고르면 3주 안에 닫힌다.

### S6.5 D+120 상한을 어떻게 할 것인가

초안의 "최소 성공 상한 D+120"은 **성립하지 않는다.** ②가 빨라야 D+118이고 ③은 규제 회신에 종속되어 통제 밖이다.

고정 상한을 늘리는 대신 **조건부로 재정의한다.**

| 항목 | 상한 |
|---|---|
| 최소 성공 ① 운영 발화 | **D+45 고정.** 내부 통제 가능. 초과 시 A10 권한으로 운영 제한 통보 + 노출 저감 조치 |
| 최소 성공 ② 기준서 서명 | **M1 전달 + 8주.** 초과 시 R-P15(주체 침묵)로 사업 총괄 에스컬레이션 |
| 최소 성공 ③ 규제 회신 | **상한 없음.** 대신 D+120 시점에 회신이 없으면 S4.3의 **잠정 조치를 의무 발동** — 자동 문자 안내 제한 또는 제한하지 않는 결정을 사업 총괄 명의로 문서화 |

**③에 고정 상한을 두지 않는 이유** — 상한을 두면 그것을 지키기 위해 "의뢰했음"으로 닫으려는 압력이 생긴다. 그것이 S1이 지운 "착수 = 성공"이다. 상한 대신 **잠정 조치를 의무화**해, 회신이 늦어도 환자 노출에 대한 결정이 공백으로 남지 않게 한다.

### S6.7 일정이 더 밀리는 조건

| 조건 | 영향 |
|---|---|
| A1a가 "분리 불가" 판정 | 탐지 전용 소멸 → ①이 M0(+5인일)와 A4 용량 결정에 묶여 **D+45로** |
| M-1 코호트 v2가 배포 번들과 크게 다름 | 차이 규명이 추가되어 1단계 **+2~3주** |
