# A1 — 안전망 EDI 이름 해소 병합 (PR 본문 초안)

## 이 PR 이 닫지 않는 것 (먼저 읽을 것)

- **A1 병합은 P0-1 을 닫지 않는다.** 병합은 코드를 main 에 올리는 것이고, 플래그는 기본 OFF 다. 안전망 정상화는 운영 트래픽에서 Top-10 발화가 관측될 때(A5) 성립한다.
- **Top-10 6/10 은 "해소 상한" 이지 운영 발화율이 아니다.** 하루치 약물 전량을 한 환자가 받았다는 극단 가정에서 그룹 조건이 채워지는 규칙 수다. 실제 환자 단위 발화는 반드시 이보다 낮다. 이 수치를 "Top-10 실증"·"안전망 정상화"·"검증됨" 으로 인용하지 말 것.
- **A4 활성은 이 PR 로 열리지 않는다.** 차단 항목이 별도로 있다(아래).

## 기본 OFF 동등성

플래그를 켜지 않은 기본 배포 상태가 현 main 과 동일함을 3층 프로토콜로 재확인했다. Round 15 당시 지문은 그 시점 main 기준이고 이후 main 이 18커밋(A2 포함) 움직였으므로 승계하지 않고 **현 main 기준으로 재실행**했다.

## A4 활성 차단 항목 — 사유 없는 Red

재측정에서 플래그를 켜면 상위 300명 중 33명이 **사유 0건인 채로 Red** 가 됐다(끈 상태 0명). 등급 산출부가 등급만 올리고 사유를 남기지 않았다. 이 PR 에서 네 조건이 각각 사유를 남기도록 고쳤고 회귀 10건으로 고정했으나, **운영 적재 상태의 실제 비율은 A5 에서 확인해야 한다.** 그 확인 전까지 A4 활성은 차단이다. 계획서 S2.2a 참조.
