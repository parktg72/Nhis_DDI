## 1. 의뢰 요지

[기관명] 이 내부 운영을 위해 구축한 **다제약물 약물상호작용 위험도 분류 시스템**(이하 "본 시스템")이 의료기기법상 **소프트웨어 의료기기에 해당하는지** 여부에 대한 유권해석을 요청합니다.

본 시스템은 현재 **453,677명 규모의 코호트를 대상으로 가동 중**이며, 사후 확인의 성격임을 아래 §5 에 밝힙니다.

## 2. 시스템 개요

| 항목 | 내용 |
|---|---|
| 목적 | 건강보험 청구데이터로 다제약물 복용 환자를 위험도에 따라 자동 분류 |
| 입력 | 처방 이력(약품코드·투여일수·기관), 연령·성별 |
| 처리 | 임상 규칙 판정 + 기계학습 분류의 **단조 상향 결합** |
| 출력 | 위험등급(4단계) + **개입 유형**(즉각 개입 / 약사 전화 / 문자 안내 / 모니터링 / 관여 안 함) |
| 사용자 | [기관] 내부 약사·담당자 |
| 환경 | 폐쇄망. 외부 연동 없음 |

## 3. 판단에 필요한 사실 — 해당성을 높이는 쪽

1. **선언된 사용 목적이 임상 의사결정 지원이다.** 내부 문서는 목적을 "예방 가능한 약물유해반응(ADR)을 사전에 차단하는 임상 의사결정 지원 체계 확립"으로 기술합니다.

2. **출력이 등급에 그치지 않고 수행할 개입 행위를 지정합니다.** 위험등급과 함께 "약사 전화", "문자 안내" 같은 행위 유형이 산출됩니다.

3. **문자 안내 등급이 210,008명(46.29%)에 부여되며, 이 등급 산출에 약사의 사전 검토가 개입하지 않습니다.**

4. **사람이 개별 판단하는 구간은 전체의 17.1%입니다.** 즉각 개입(0.37%)과 약사 전화(16.75%)를 합한 값이며, 어떤 형태로든 등급이 부여되는 환자는 99.96%입니다.

5. **임상 판정 기준서가 미승인 초안 상태입니다.** 문서 상태가 "초안", 승인란이 서명되지 않았으며, 최고위험(Red) 7개 조건 중 6개가 임상 전문가 서명 없이 하위 등급으로 조정된 채 운영되고 있습니다. 그 조정으로 인한 미탐지 증가는 측정되지 않았습니다.

6. **독립적인 임상 성능 검증이 없습니다.** 전문가가 규칙과 독립적으로 판정한 정답 데이터가 0건입니다. 내부 교차검증에서 산출된 완전분류 지표는 정답이 입력 피처의 결정론적 함수인 데서 오는 **규칙 재현 충실도**이며 예측 성능이 아닙니다.

7. **시판 후 감시 수단이 없습니다.** 감사 로그·운영 대시보드·드리프트 산출이 모두 미가동이며, 중대 오류를 탐지할 수단이 없어 비상 대응 절차가 구조적으로 발동하지 못합니다.

## 4. 판단에 필요한 사실 — 해당성을 낮추는 쪽

위 사실만으로 판단하면 과잉 규제가 됩니다. 아래를 함께 고려해 주시기 바랍니다.

1. **실질적인 판정 함수는 결정론적 임상 규칙이며, 기계학습은 그 위에 단방향으로만 작용합니다.** 학습 모델은 규칙이 정한 등급을 **낮출 수 없고 올릴 수만** 있습니다. 절대 금기 판정은 모델과 무관한 별도 백스톱이 강제하며, 규칙이 보장하는 최소 등급은 단방향 하한으로 고정됩니다.

2. **자동 통보 기능이 구현되어 있지 않습니다.** 문자·전화·메일 등 어떤 발송 연동도 존재하지 않습니다. 개입 유형은 API 응답 필드와 오프라인 산출물(대상자 목록·보고서)로 전달되며, **실제 연락 여부와 방법은 사람이 결정하고 수행**합니다. §3 의 3항을 "인구 규모 자동 통보"로 읽어서는 안 됩니다.

3. **안전 규칙층 일부가 비활성 상태입니다.** 환경 설정으로 꺼져 있으며, 활성화 시 즉각 개입 대상이 증가합니다. 다만 그 증가폭 근거는 150명·1일치 표본의 점추정으로 신뢰구간이 산출되지 않았고, 전체 코호트 기준 재측정이 예정돼 있습니다.

4. **활성화가 안전 규칙 전체를 복구하지도 않습니다.** 일부 판정 경로는 별도의 참조 데이터 확보가 선행되어야 동작합니다.

## 5. 선행 자기분류 고지

본 시스템은 내부적으로 **비(非)의료기기(내부 행정 지원 도구)** 로 분류하여 개발·운영되어 왔으며, 관련 문서에도 그 지위 유지가 전제되어 있습니다. 본 의뢰는 그 자기분류가 타당한지를 **사후에 확인**하려는 것입니다.

기존 내부 논거는 "학습 모델의 출력은 참고 정보 필드일 뿐 위험도를 구동하지 않는다" 였으나, 검토 결과 **그 한정은 보조 모델에만 해당하고 실제 운영 모델에는 적용되지 않음**을 확인했습니다. 따라서 그 논거는 본 의뢰에서 철회하며, §3·§4 의 사실에 근거해 판단해 주시기를 요청합니다.
