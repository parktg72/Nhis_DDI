# 임상 판정 기준서 검토 착수 요청 (초안)

- 작성 2026-09-01 · **개정 2026-09-02** · 개선계획 0단계 **B1**
- 상태: **초안 — 수신자·일정 기입 후 발송**
- 근거: `docs/plans/2026-09-01-mode11-개선계획.md` §S2.2 · §S4.2

> **2026-09-02 개정 요지** — 작성 후 시스템에서 두 가지가 확인·수정됐고, 그것이 검토 대상을 바꿉니다.
> ① 판정 규칙 10종 중 **4종이 그동안 실제로 발화하지 않고 있었습니다**(§1.2). ② 그 결과 "측정 불가" 로 안내드렸던 **QT 조건이 이제 측정 가능해졌습니다**(§3.1). 공란 수용 요청을 철회합니다.

> **이 문서가 요청하는 것은 승인이 아닙니다.**
> 지금 요청하는 것은 ① **검토 주체 4인 지정** ② **검토 일정 합의** 두 가지입니다.
> 서명은 §3 의 측정이 끝난 뒤(약 2~3개월 후) 별도 패킷으로 요청드립니다.
> 측정 없이 서명을 요청하는 것은, 무엇을 승인하는지 모르는 상태에서 책임을 지게 하는 일입니다.

## 1. 현재 상태 — 있는 그대로

본 시스템의 위험도 판정은 `CLINICAL_STANDARDS` 기준서에서 파생됩니다. 그 기준서의 현재 상태는 다음과 같습니다.

| 항목 | 상태 |
|---|---|
| 문서 버전 | 파일명은 v1.0, 문서 헤더 상태는 **"초안 (팀 검토 후 확정)"** |
| 변경 이력 | **0.1 (초안 작성) 한 줄** |
| 승인란 | 4칸 중 실질 서명 **0건** (승인 상태 "승인 대기") |
| 적용 규모 | 이 기준에서 파생된 라벨로 **453,677명이 분류돼 운영 중** |

즉 **미승인 초안 위에서 45만 명 규모의 판정이 이루어지고 있습니다.** 이것이 이 요청의 이유입니다.

### 1.1 그동안 일어난 변경

기준서가 규정한 최고위험(Red) 7개 조건 중 **실제로 Red 로 유지된 것은 1개(절대 금기)** 뿐입니다. 나머지 6개에 일어난 일은 서로 다릅니다 — **"하위 등급 조정" 으로 뭉뚱그렸던 종전 서술을 아래 표로 정정합니다.**

| # | 기준서의 Red 조건 | 실제로 일어난 일 |
|---|---|---|
| 1 | 금기 DDI 1건 이상 | **Red 유지** |
| 2 | Major DDI **3건 이상** | **건수 구분이 사라졌습니다.** 하위 등급(약사 전화)으로 내려가면서 Major **1건**과 같은 취급이 됐습니다. 3건과 1건이 구분되지 않습니다 |
| 3 | Triple Whammy | 하위 등급으로 조정 (즉시 개입은 유지) |
| 4 | 10종 이상 + **Major DDI 1건 이상** | **다른 조건으로 바뀌었습니다.** 현재 코드는 `10종 이상 + 고위험 약물` 을 봅니다 — 기준서에 없는 조건입니다. 기준서의 조건 4 는 어디에도 없습니다 |
| 5 | **고위험 약물 + Major DDI** | **없습니다.** 하위 등급으로도 남아 있지 않습니다 |
| 6 | 75세 이상 + 5종 이상 + 신/간 위험 약물 | 하위 등급으로 조정 (즉시 개입은 유지) |
| 7 | QT 연장 약물 3종 이상 | 라벨 판정 경로에 **없습니다.** 서빙 안전망에는 있습니다(§1.3) |

**조건 4·5·7 은 "조정" 이 아닙니다.** 4 는 다른 조건으로 치환됐고 5·7 은 사라졌습니다. 종전 문안대로면 선생님들께서 **직접 쓰지 않으신 조건**(`10종 + 고위험 약물`)에 서명하시게 됩니다. 그 점을 바로잡습니다.

이 조정은 **임상 전문가 서명 없이** 이루어졌고, 기준서 버전도 올라가지 않았습니다. 조정 자체가 잘못이라는 뜻이 아닙니다 — 과경보 문제(Red 비율이 한때 25.8%까지 상승)에 대한 대응이었습니다. 문제는 **그 판단이 임상 소유권 없이 내려졌고, 그로 인한 미탐지 증가가 측정되지 않았다**는 점입니다.

### 1.2 규칙 4종이 그동안 발화하지 않았습니다 (2026-09-02 확인·수정)

기준서에서 파생된 판정 규칙 10종 중 **4종이 실제 청구 데이터에서 한 번도 발화하지 않고 있었습니다.** 규칙 자체는 코드에 있었으나, 약품코드를 성분명으로 되돌리는 단계가 끊겨 규칙에 입력이 도달하지 않았습니다.

| 규칙 | 임상 내용 | 그동안 |
|---|---|---|
| Triple Whammy | ACEi/ARB + K보존이뇨제 + NSAID → 급성신손상 | 무발화 |
| Digoxin + Amiodarone·Verapamil | 디곡신 중독 | 무발화 |
| **Methotrexate + Trimethoprim** | **병용 금기** | 무발화 |
| **Statin + Macrolide** | **횡문근융해** | 무발화 |

원인은 참조 데이터 부재가 아니라 식별자 연결 결함이었습니다 — 해당 약물은 마스터에 있고 실제로 처방되고 있었습니다. 2026-09-02 에 수정했고, 약물명 해소율이 60.2% → 80.7% 로 올라가며 **10종 전부가 발화 가능**해졌습니다.

**이 사실이 검토 대상을 바꿉니다.** 종전이라면 검토진은 *문서상으로만 존재하고 실제로는 작동하지 않던* 조건을 검토하게 되었을 것입니다. 지금은 실제로 발화하는 조건을 검토하시게 됩니다. 아래 §3.2 에 그 규모를 실측으로 제시합니다.

수정 전후로 **개입 등급·개입 지시는 바뀌지 않았습니다.** 탐지가 늘었을 뿐이며, 늘어난 탐지를 개입으로 연결할지는 이 검토와 별도의 운영 결정입니다.


### 1.3 판정 경로가 둘이고 서로 다릅니다

라벨 판정 경로(45만 명 분류에 쓰인 것)와 서빙 안전망(요청 시점에 도는 것)이 같은 기준서에서 갈라져 나왔으나 **현재 서로 다릅니다.** 서빙 안전망은 조건 2(Major 3건)와 조건 7(QT 3종)을 Red 조건으로 갖고 있어 **기준서에 더 가깝습니다.**

즉 셋이 서로 다릅니다 — **기준서 ≠ 라벨 경로 ≠ 서빙 경로.** 어느 것을 정본으로 삼을지가 검토 대상에 포함됩니다. 이 요청서가 답을 드리지 않고 사실만 알려드리는 이유는, 그 선택이 임상 판단이기 때문입니다.

## 2. 요청 사항

### 2.1 검토 주체 4인 지정

기준서 승인란에 대응하는 네 역할의 담당자를 지정해 주시기 바랍니다.

| 역할 | 검토 관점 |
|---|---|
| 약물전문가 (임상약사) | 판정 조건의 임상 타당성, 등급 조정의 수용 여부 |
| 모델연구원 | 규칙과 학습 모델의 결합 방식 |
| QA검증전문가 | 검증 가능성, 배포 게이트 |
| Team Lead | 문서 확정 및 변경 관리 |

### 2.2 검토 일정 합의

측정 산출(약 D+90 예정) 이후 **서명까지 4~8주**를 계획에 반영했습니다. 실제 가용 일정을 알려주시면 계획을 그에 맞춰 조정합니다.

**이 일정이 전체 과제의 임계경로 중 하나입니다.** 서명이 나기 전에는 재학습·피처 확장 등 후속 작업을 진행하지 않습니다 — 미승인 기준 위에서 라벨을 다시 만들면 승인 시 전량 폐기이기 때문입니다.

## 3. 서명 전에 제공될 측정 — 지금 공유하는 이유

**"6개 조건을 낮췄는데 그 영향은 모른다"고 서명을 요청할 수는 없습니다.** 따라서 아래를 먼저 산출한 뒤 패킷으로 제출합니다. 측정 항목이 검토에 충분한지 지금 알려주시면 설계를 조정할 수 있습니다.

| # | 측정 | 답하는 질문 |
|---|---|---|
| M1 | 강등 조건 해당 환자 수 **× 현재 개입 강도 교차표** | 얼마나 낮췄고, 그 환자들은 지금 무엇을 받는가 |
| M1b | **조건별 반사실 Red 규모** | 조건 i 를 Red 로 되돌리면 즉각 개입이 몇 명이 되는가 |
| M1c | Major DDI ∩ 3제 병용 인원 3분할 | 위계 순서 문제의 임상 영향 |
| M1d | 경계 검토 큐 통과 인원 | 사람이 실제로 걸러내는 양 |
| M1e | 연령·성별 층화 | 강등이 특정 집단에 몰렸는가 |
| M2·M3 | 절단·중첩 임계의 영향 | 판정 로직 자체의 누락 가능성 |
| M4 | 상호작용 등급 출처 간 일치율 | 등급 판정의 신뢰도 |
| **M5** | **QT 연장 조건 전체 코호트 측정** (§3.1) | 공란으로 남겨질 뻔했던 조건의 실제 규모 |
| **M6** | **신규 발화 4종의 전체 코호트 규모 + 개입 강도 교차표** (§3.2) | 그동안 무발화였던 조건이 켜지면 누가 무엇을 받게 되는가 |
| **M7** | **무발화 기간의 미탐지 추정** | 4종이 작동하지 않은 동안 놓친 환자 규모 |

### 3.1 QT 조건 — 측정 불가 안내를 철회합니다

작성 시점에는 **QT 연장 조건을 측정할 수 없다**고 안내드렸고, 서명 패킷에서 해당 칸을 공란으로 제출하며 그 사실을 인지하셨다는 확인을 요청드릴 예정이었습니다.

**§1.2 의 수정으로 QT 약물이 해소되기 시작해 이 조건은 측정 가능해졌습니다.** 공란 수용 요청을 철회하고, 다른 조건과 같은 형식으로 측정치를 제출합니다.

선행 실측(2024-07-01 하루치, 무작위 3,000명, 시드 고정):

| QT 연장 약물 동시 처방 수 | 환자 수 | 비율 |
|---|---|---|
| 0종 | 2,684 | 89.5% |
| 1종 | 127 | 4.2% |
| 2종 | 129 | 4.3% |
| **3종 이상 (Red 조건 성립)** | **60** | **2.00%** |

최대 18종까지 관측됐습니다. 정식 측정은 서명 패킷에서 전체 코호트 기준으로 제출합니다.

**다만 이 측정의 성격을 미리 밝혀 둡니다.** 판정 규칙을 코호트에 적용해 **대상 규모를 세는 것**이며, 현행 등급·모델의 재구성이 아닙니다. 분모·동시 처방의 정의·약품코드 해소율을 함께 제시하겠습니다. 위 하루치 수치는 **예비치**이며 전체 코호트로 외삽하지 않습니다.

**한 가지 확정을 함께 요청드립니다.** QT 연장 약물의 목록이 현재 시스템 안에 **둘** 있고 서로 다릅니다(한쪽에만 있는 약효군이 양쪽에 각각 존재). 어느 것을 기준으로 삼느냐에 따라 위 숫자가 달라지므로, 정식 측정 전에 기준 목록을 정해 주셔야 합니다 (§7).

### 3.2 신규 발화 4종의 규모 — 선행 실측

§1.2 에서 수정된 규칙들이 실제로 얼마나 해당되는지 미리 제시합니다. 같은 표본(하루치 3,000명) 기준입니다.

| 규칙 | 해당 환자 | 비율 |
|---|---|---|
| QT 연장 3종 이상 | 60 | 2.00% |
| Clopidogrel + PPI | 38 | 1.27% |
| 항응고제 + NSAID | 8 | 0.27% |
| **Triple Whammy** | **3** | **0.10%** |
| **Digoxin + Amiodarone·Verapamil** | **2** | **0.07%** |
| **Statin + Macrolide** | **1** | **0.03%** |
| **Methotrexate + Trimethoprim** | **0** | 표본 내 병용 없음 |
| Top-10 중 1개 이상 해당 | 106 | 3.53% |

**규모가 작다는 것이 중요도가 낮다는 뜻은 아닙니다.** 병용 금기(Methotrexate + Trimethoprim)와 중증 이상반응(Statin + Macrolide)은 발생 빈도가 낮고 결과가 무거운 유형입니다. 표본에서 0~1명이라는 사실 자체가 검토 판단의 재료입니다.

**이 수치는 하루치 표본이며 요일·계절 편향이 있습니다.** 전체 코호트 기준 측정은 서명 패킷에서 제출합니다.

## 4. 서명 시 요청될 형식 — 미리 알려드립니다

서명 단계에서 다음을 요청드릴 예정입니다. 지금 알려드리는 것은 검토 준비에 필요하기 때문입니다.

1. **서명자별 판단 근거 1문단** — 무엇을 보고 무엇을 승인했는지. 빈 서명은 받지 않습니다.
2. **조건별 명시적 결정** — 강등 5개 조건 각각에 **유지 / Red 복원 / 조건 변경** 중 하나. 반사실 규모(M1b)를 근거로 인용. **일괄 승인은 요청하지 않습니다.**
3. **신규 발화 4종 각각에 대한 결정** — §1.2 에서 되살아난 네 조건에 **탐지 유지 / 개입 연결 / 조건 변경** 중 하나. 특히 병용 금기(Methotrexate + Trimethoprim)와 중증 이상반응(Statin + Macrolide)은 개별 판단을 요청드립니다.
4. **등급 사유 문구 확인** — 개입 등급이 올라갈 때 함께 전달되는 사유 문구가 임상적으로 타당한지. 종전에는 사유 없이 "즉각 개입(약사 직접 연락)" 지시만 전달되는 경로가 있었고 2026-09-02 에 수정했습니다.
5. **재검토 기한 합의** — 승인은 무기한이 아니며, 독립 검증 데이터 확보 후 재확인 대상입니다.

## 5. 거부는 정상 결과입니다

강등 조건 유지를 **거부하시는 것도 정상적인 결과**입니다. 그 경우 라벨 재생성과 개입 위계 재설계가 후속 범위에 들어오고 일정이 재산정됩니다.

이를 미리 밝히는 이유는, **거부하는 쪽이 더 비싸 보여서 승인이 유도되는 상황을 만들지 않기 위해서**입니다. 계획 문서에도 이 분기를 비용과 함께 기재해 두었습니다.

## 6. 함께 알려드리는 한계

검토에 영향을 줄 수 있는 사실을 미리 밝힙니다.

- **독립적인 임상 성능 검증이 없습니다.** 전문가가 규칙과 독립적으로 판정한 정답 데이터가 0건이며, 내부 교차검증 지표는 규칙 재현 충실도이지 예측 성능이 아닙니다.
- **기존 시스템과의 비교가 없습니다.** 현행 DUR 대비 우위는 측정되지 않았습니다.
- **규칙이 작동하는지 자체를 확인하는 절차가 없었습니다.** §1.2 의 4종 무발화는 규칙 로직의 오류가 아니라 데이터가 규칙에 도달하지 못한 문제였고, 그것을 잡아내는 검증이 없어 오래 지속됐습니다. 현재는 각 규칙이 실제 청구 코드로 발화하는지 확인하는 검사를 두었습니다.
- **판정 규칙 자체가 검증받은 적이 없습니다.** 성분명 키워드 매칭, 중첩 일수 임계, 윈도우당 약물 수 상한 등이 임상 검토 없이 운영되고 있습니다. §3 의 M2·M3 가 그 영향을 정량화합니다.
