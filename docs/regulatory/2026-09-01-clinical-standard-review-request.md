# 임상 판정 기준서 검토 착수 요청 (초안)

- 작성 2026-09-01 · 개선계획 0단계 **B1**
- 상태: **초안 — 수신자·일정 기입 후 발송**
- 근거: `docs/plans/2026-09-01-mode11-개선계획.md` §S2.2 · §S4.2

> **이 문서가 요청하는 것은 승인이 아닙니다.**
> 지금 요청하는 것은 ① **검토 주체 4인 지정** ② **검토 일정 합의** 두 가지입니다.
> 서명은 §3 의 측정이 끝난 뒤(약 2~3개월 후) 별도 패킷으로 요청드립니다.
> 측정 없이 서명을 요청하는 것은, 무엇을 승인하는지 모르는 상태에서 책임을 지게 하는 일입니다.

---

## 1. 현재 상태 — 있는 그대로

본 시스템의 위험도 판정은 `CLINICAL_STANDARDS` 기준서에서 파생됩니다. 그 기준서의 현재 상태는 다음과 같습니다.

| 항목 | 상태 |
|---|---|
| 문서 버전 | 파일명은 v1.0, 문서 헤더 상태는 **"초안 (팀 검토 후 확정)"** |
| 변경 이력 | **0.1 (초안 작성) 한 줄** |
| 승인란 | 4칸 중 실질 서명 **0건** (승인 상태 "승인 대기") |
| 적용 규모 | 이 기준에서 파생된 라벨로 **453,677명이 분류돼 운영 중** |

즉 **미승인 초안 위에서 45만 명 규모의 판정이 이루어지고 있습니다.** 이것이 이 요청의 이유입니다.

### 1.1 그동안 일어난 변경

기준서가 규정한 최고위험(Red) 7개 조건 중 **실제로 Red 로 유지된 것은 1개(절대 금기)** 이며, 나머지 6개는 하위 등급으로 조정되었습니다.

이 조정은 **임상 전문가 서명 없이** 이루어졌고, 기준서 버전도 올라가지 않았습니다. 조정 자체가 잘못이라는 뜻이 아닙니다 — 과경보 문제(Red 비율이 한때 25.8%까지 상승)에 대한 대응이었습니다. 문제는 **그 판단이 임상 소유권 없이 내려졌고, 그로 인한 미탐지 증가가 측정되지 않았다**는 점입니다.

## 2. 요청 사항

### 2.1 검토 주체 4인 지정

기준서 승인란에 대응하는 네 역할의 담당자를 지정해 주시기 바랍니다.

| 역할 | 검토 관점 |
|---|---|
| 약물전문가 (임상약사) | 판정 조건의 임상 타당성, 등급 조정의 수용 여부 |
| 모델연구원 | 규칙과 학습 모델의 결합 방식 |
| QA검증전문가 | 검증 가능성, 배포 게이트 |
| Team Lead | 문서 확정 및 변경 관리 |

### 2.2 검토 일정 합의

측정 산출(약 D+90 예정) 이후 **서명까지 4~8주**를 계획에 반영했습니다. 실제 가용 일정을 알려주시면 계획을 그에 맞춰 조정합니다.

**이 일정이 전체 과제의 임계경로 중 하나입니다.** 서명이 나기 전에는 재학습·피처 확장 등 후속 작업을 진행하지 않습니다 — 미승인 기준 위에서 라벨을 다시 만들면 승인 시 전량 폐기이기 때문입니다.

## 3. 서명 전에 제공될 측정 — 지금 공유하는 이유

**"6개 조건을 낮췄는데 그 영향은 모른다"고 서명을 요청할 수는 없습니다.** 따라서 아래를 먼저 산출한 뒤 패킷으로 제출합니다. 측정 항목이 검토에 충분한지 지금 알려주시면 설계를 조정할 수 있습니다.

| # | 측정 | 답하는 질문 |
|---|---|---|
| M1 | 강등 조건 해당 환자 수 **× 현재 개입 강도 교차표** | 얼마나 낮췄고, 그 환자들은 지금 무엇을 받는가 |
| M1b | **조건별 반사실 Red 규모** | 조건 i 를 Red 로 되돌리면 즉각 개입이 몇 명이 되는가 |
| M1c | Major DDI ∩ 3제 병용 인원 3분할 | 위계 순서 문제의 임상 영향 |
| M1d | 경계 검토 큐 통과 인원 | 사람이 실제로 걸러내는 양 |
| M1e | 연령·성별 층화 | 강등이 특정 집단에 몰렸는가 |
| M2·M3 | 절단·중첩 임계의 영향 | 판정 로직 자체의 누락 가능성 |
| M4 | 상호작용 등급 출처 간 일치율 | 등급 판정의 신뢰도 |

### 3.1 측정할 수 없는 것

**QT 연장 조건은 측정이 불가능합니다.** 해당 피처가 산출되지 않아 데이터에 존재하지 않습니다. 서명 패킷에서 이 칸은 **공란**으로 제출되며, 측정 수단 부재를 인지하셨다는 확인을 별도 항목으로 요청드릴 예정입니다.

## 4. 서명 시 요청될 형식 — 미리 알려드립니다

서명 단계에서 다음을 요청드릴 예정입니다. 지금 알려드리는 것은 검토 준비에 필요하기 때문입니다.

1. **서명자별 판단 근거 1문단** — 무엇을 보고 무엇을 승인했는지. 빈 서명은 받지 않습니다.
2. **조건별 명시적 결정** — 강등 5개 조건 각각에 **유지 / Red 복원 / 조건 변경** 중 하나. 반사실 규모(M1b)를 근거로 인용. **일괄 승인은 요청하지 않습니다.**
3. **QT 공란 수용 확인** — §3.1
4. **재검토 기한 합의** — 승인은 무기한이 아니며, 독립 검증 데이터 확보 후 재확인 대상입니다.

## 5. 거부는 정상 결과입니다

강등 조건 유지를 **거부하시는 것도 정상적인 결과**입니다. 그 경우 라벨 재생성과 개입 위계 재설계가 후속 범위에 들어오고 일정이 재산정됩니다.

이를 미리 밝히는 이유는, **거부하는 쪽이 더 비싸 보여서 승인이 유도되는 상황을 만들지 않기 위해서**입니다. 계획 문서에도 이 분기를 비용과 함께 기재해 두었습니다.

## 6. 함께 알려드리는 한계

검토에 영향을 줄 수 있는 사실을 미리 밝힙니다.

- **독립적인 임상 성능 검증이 없습니다.** 전문가가 규칙과 독립적으로 판정한 정답 데이터가 0건이며, 내부 교차검증 지표는 규칙 재현 충실도이지 예측 성능이 아닙니다.
- **기존 시스템과의 비교가 없습니다.** 현행 DUR 대비 우위는 측정되지 않았습니다.
- **판정 규칙 자체가 검증받은 적이 없습니다.** 성분명 키워드 매칭, 중첩 일수 임계, 윈도우당 약물 수 상한 등이 임상 검토 없이 운영되고 있습니다. §3 의 M2·M3 가 그 영향을 정량화합니다.

## 부기 — 이 요청서의 원칙

**측정이 결정에 앞섭니다.** 이 과제에서 반복된 실패 패턴이 미측정 상태의 임상 결정이었습니다. Red 조건 강등도, 위험약물 목록 확장 보류도 영향을 재지 않은 채 내려졌습니다. 같은 패턴을 승인 절차에서 반복하지 않기 위해 서명을 측정 뒤로 두었습니다.

**추인을 요청하지 않습니다.** §4 의 네 형식은 서명이 현 상태 추인으로 흐르지 않도록 하는 장치입니다. 승인란을 채우는 것이 목적이라면 이 요청서는 필요 없습니다.
